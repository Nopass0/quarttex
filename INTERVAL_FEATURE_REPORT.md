# Отчет о реализации интервала между сделками

## Обзор
Успешно реализована функциональность настройки интервала в минутах между сделками для реквизитов. Интервал настраивается индивидуально для каждого реквизита и учитывается при создании новых сделок.

## Что было реализовано

### 1. База данных
- ✅ Поле `intervalMinutes` уже существовало в таблице `BankDetail`
- ✅ Поле корректно обрабатывается во всех операциях с реквизитами

### 2. Backend API
- ✅ **Утилитная функция**: `backend/src/utils/requisite-interval.ts`
  - `canCreateDealOnRequisite()` - проверяет можно ли создать сделку с учетом интервала
  - `getWaitTimeForNextDeal()` - возвращает время ожидания до следующей сделки
  
- ✅ **Проверка интервала добавлена в**:
  - `backend/src/routes/merchant/index.ts` - основной API создания сделок
  - `backend/src/routes/admin/transactions.ts` - административные инструменты
  - `backend/src/routes/wellbit/payment.ts` - Wellbit интеграция

- ✅ **API endpoints поддерживают intervalMinutes**:
  - `/trader/bank-details` - создание и обновление обычных реквизитов
  - `/trader/bt-entrance/requisites` - создание и обновление БТ-входа реквизитов

### 3. Frontend формы
- ✅ **Обновлены компоненты**:
  - `frontend/components/trader/requisites-sheet.tsx` - форма обычных реквизитов
  - `frontend/components/trader/bt-requisites-sheet.tsx` - форма БТ-входа реквизитов
  
- ✅ **Добавлено поле "Интервал между сделками (мин)"**:
  - Валидация схемы Zod
  - Состояние формы и локальные переменные
  - UI поле с описанием "0 = без ограничений"
  - Корректная обработка при создании и редактировании

### 4. Логика работы
- ✅ **Алгоритм проверки**:
  - При `intervalMinutes = 0` - ограничения нет
  - При `intervalMinutes > 0` - проверяется время последней сделки
  - Учитываются все статусы сделок: CREATED, IN_PROGRESS, READY, CANCELED
  - Логирование для отладки

- ✅ **Интеграция с выбором реквизитов**:
  - Реквизиты с неистекшим интервалом исключаются из выбора
  - Работает во всех точках создания сделок

### Логика проверки интервала:
```typescript
// Проверяем интервал между сделками
if (bd.intervalMinutes > 0) {
  const { canCreateDealOnRequisite } = await import("@/utils/requisite-interval");
  const canCreate = await canCreateDealOnRequisite(bd.id, bd.intervalMinutes);
  if (!canCreate) {
    console.log(`Реквизит ${bd.id} отклонен: не прошел интервал ${bd.intervalMinutes} минут между сделками`);
    continue;
  }
}
```

## Как использовать

### Для трейдеров:
1. При создании/редактировании реквизита указать интервал в минутах
2. `0` = без ограничений (по умолчанию)
3. `> 0` = минимальный интервал между сделками на этом реквизите

### Для системы:
- Автоматически учитывается при создании сделок
- Реквизиты с неистекшим интервалом исключаются из выбора
- Логирование в консоль для мониторинга
