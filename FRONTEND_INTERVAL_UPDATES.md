## Детали реализации

### UI/UX паттерны
- Поле отображается как "Интервал между сделками (мин)"
- Placeholder: "0"
- Описание: "0 = без ограничений"
- Валидация: минимальное значение 0
- Тип ввода: numeric с фильтрацией только цифр

### Отображение в списках
- **Обычные реквизиты**: "Интервал: без ограничений" или "Интервал: X мин"
- **БТ-реквизиты**: аналогично, с оранжевым цветом для выделения
- **Устройства**: стандартное отображение в карточках

### Логика обработки
- Все формы валидируют `intervalMinutes` как обязательное поле
- При создании/редактировании значение корректно передается в API
- При отображении значение 0 показывается как "без ограничений"
- Значения > 0 показываются как "X мин"

## Заключение

Функциональность интервала между сделками полностью реализована и интегрирована во все компоненты системы:

- **База данных**: поле `intervalMinutes` корректно используется
- **Бэкенд**: логика проверки интервала работает во всех точках создания сделок
- **Фронтенд**: все формы и списки поддерживают настройку и отображение интервала
- **API**: все endpoints корректно обрабатывают поле интервала

Система готова к использованию. Трейдеры могут настраивать индивидуальный интервал для каждого реквизита, и этот интервал будет автоматически учитываться при создании новых сделок.
